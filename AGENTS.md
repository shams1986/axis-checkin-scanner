# Agent Working Rules

These rules apply to AI agents and Codex when working in this repository.

1. Always inspect the repository before changing files.
2. Always run `git status`, or ask the user to run it when necessary, before starting work.
3. Do not modify production-critical code unless the task explicitly asks for it.
4. Do not push to GitHub without explicit user approval.
5. Do not run `clasp push` without explicit user approval.
6. Read `DEPLOYMENT.md` before any deployment-related task.
7. For frontend changes, avoid changing Apps Script unless required.
8. For Apps Script changes, preserve the existing public API response format unless explicitly asked to change it.
9. Show the diff before committing.
10. Prefer small, focused changes over large refactors.
11. The production AXIS Check-in system is currently working, so avoid broad rewrites.
12. If uncertain, explain the risk instead of making a risky change.
